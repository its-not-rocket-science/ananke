WASM / Browser Example

Ananke running entirely in the browser — pure-JS fallback always active; upgrades to WebAssembly if the compiled binary is available alongside this page.

HP drains each step. Entity 0 moves right (+x) per step command; others are stationary in this demo.

// 3. Same API surface regardless of backend
bridge.world_create(seed);

bridge.world_extractSnapshot();

WASM binary built via npm run build:wasm:core. Without it the TS fallback provides deterministic step semantics using a simple LCG simulation. Both backends expose the same AnankeWasmBridge interface.
